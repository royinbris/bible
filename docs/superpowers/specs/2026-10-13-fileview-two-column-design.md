# 파일뷰 2단 미리보기 — 설계

- 일자: 2026-10-13
- 상태: 사용자 승인됨
- 범위: 맥북 넓이(768px 이상) 미리보기 2컬럼 + 1단/2단 토글. 가로 페이지 넘김은 범위 밖.

## 1. 목표

맥북에서 파일뷰 미리보기를 신문처럼 2단으로 읽는다. 편집기는 숨김 유지.

## 2. 동작

- 툴바에 1단/2단 토글 버튼 추가. 768px 미만에서는 숨김.
- 선택값은 `localStorage('fileview_two_column')`에 저장, 기본 `'0'`(1단).
- 2단이면 파일뷰 컨테이너 최대너비를 600px에서 1000px로 확장하고
  미리보기 본문에 `column-count: 2; column-gap: 40px` 적용.
- 읽기 순서: 왼쪽 칼럼(앞부분) → 오른쪽 칼럼(뒷부분).
- TTS 강조·자동 스크롤·이어듣기 로직은 그대로 (세로 스크롤 유지).

## 3. 에러 처리

- 해당 없음 (표시 전용, 기존 폴백 없음).

## 4. 테스트

- `npm run build` 통과.
- 맥북 넓이에서 1단↔2단 전환, 새로고침 후 선택 유지, TTS 재생 중 강조 정상.
- 아이폰 넓이에서 토글 숨김 + 기존 1단 동작 불변.

## 5. 범위 밖

- 가로 페이지 넘김, 편집기+미리보기 분할, 단 수(3단 이상) 선택.
