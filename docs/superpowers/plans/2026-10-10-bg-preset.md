# 배경색 프리셋 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설정 모양 탭에서 앱 전체 배경 프리셋(기본·크림·세피아·그린·그레이)을 고를 수 있게 한다.

**Architecture:** `user_settings.bgPreset` 키 하나로 상태를 들고, `SettingsContext`가 `<html data-bg>` + `data-theme` 강제 `light`로 적용한다. 실제 색은 `index.css`의 프리셋별 CSS 변수 블록이 담당한다. 기존 테마 코드는 손대지 않는다.

**Tech Stack:** React 19, Vite 8, vanilla CSS variables, Playwright e2e.

## Global Constraints

- 프리셋은 라이트 종이색만 제공한다. 다크 계열·컬러피커·화면별 개별 배경은 범위 밖이다.
- 프리셋 선택 시 `data-theme`은 `'light'`로 강제한다 (다크 전용 분기 어긋남 방지).
- 기존 저장값에 `bgPreset`이 없으면 `'default'` (현재 동작 그대로)이다.
- `user_settings` 동기화 흐름은 건드리지 않는다 (자동으로 따라간다).

---

- [ ] **Step 1: 실패하는 e2e 테스트 작성**

`app/tests/bg-preset.spec.js` 신규 생성 (아래 전문 그대로):

```js
import { test, expect } from '@playwright/test';

const SETTINGS_BASE = {
  fontSize: 18,
  fontWeight: 400,
  lineHeight: 1.7,
  verseSpacing: 0.8,
  horizontalPadding: 1.5,
  fontFamily: 'System Default',
  theme: 'system',
  bibleLanguage: 'ko',
  prayerTtsRate: 0.85,
};

test('그린 프리셋이면 data-bg=green + data-theme 강제 light + 배경색 적용', async ({ page }) => {
  await page.emulateMedia({ colorScheme: 'dark' });
  await page.addInitScript((base) => {
    localStorage.setItem('user_settings', JSON.stringify({ ...base, bgPreset: 'green' }));
  }, SETTINGS_BASE);
  await page.goto('/home');
  await expect(page.locator('html')).toHaveAttribute('data-bg', 'green');
  await expect(page.locator('html')).toHaveAttribute('data-theme', 'light');
  const bg = await page.evaluate(() => getComputedStyle(document.body).backgroundColor);
  expect(bg).toBe('rgb(231, 239, 226)');
});

test('기본값이면 data-bg 속성이 없음', async ({ page }) => {
  await page.addInitScript((base) => {
    localStorage.setItem('user_settings', JSON.stringify({ ...base }));
  }, SETTINGS_BASE);
  await page.goto('/home');
  await expect(page.locator('html')).not.toHaveAttribute('data-bg', 'green');
});
```

`app/src/context/SettingsContext.jsx`에 아래 3곳을 수정한다.

(a) DEFAULT_SETTINGS에 키 추가:

```js
const DEFAULT_SETTINGS = {
  fontSize: 18,
  fontWeight: 400,
  lineHeight: 1.7,
  verseSpacing: 0.8,
  horizontalPadding: 1.5,
  fontFamily: 'System Default',
  theme: 'system',
  bibleLanguage: 'ko',
  prayerTtsRate: 0.85,
  bgPreset: 'default'
};
```

(b) 로드 시 정규화 (`SettingsProvider` 안 `useState` 초기화 교체):

```js
const BG_PRESETS = ['default', 'cream', 'sepia', 'green', 'gray'];

const [settings, setSettings] = useState(() => {
  const saved = localStorage.getItem('user_settings');
  const parsed = saved ? JSON.parse(saved) : { ...DEFAULT_SETTINGS };
  if (!BG_PRESETS.includes(parsed.bgPreset)) parsed.bgPreset = 'default';
  return parsed;
});
```

(c) effect末尾에 프리셋 적용 (기존 theme 적용 코드 바로 뒤):

```js
const preset = settings.bgPreset || 'default';
if (preset === 'default') {
  document.documentElement.removeAttribute('data-bg');
} else {
  document.documentElement.setAttribute('data-theme', 'light');
  document.documentElement.setAttribute('data-bg', preset);
}
```
